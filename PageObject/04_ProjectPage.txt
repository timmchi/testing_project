# Positive Tests SEE IF IT IS ACTUALLY THE SAME NAMING IN GITLAB

	Create blank project
     - Open projects page    ProjectUrl
     - Click "New project"
     - Select "Create blank project"
     - Input Project Name   ProjectName
     - Input Project slug   ProjectSlug
     - Select Visbility level   VisibilityPrivate
     - Press Create Project Button
     - Verify the Project was created successfully
     - Verify Page contains     ExpectedSuccessMsg

	Create template project 
     - Open projects page    ProjectUrl
     - Click "New project"
     - Select Create From Template
     - Choose Template
     - Input Project Name   TemplateProjectName
     - Select Visibility Level  VisibilityPrivate
     - Click Create Project Button
     - Verify Page contains     ExpectedSuccessMsg

	Update name of template project 
     - Open created Template project
     - Navigate to Project Settings
     - Open General Settings
     - Input New Project Name   UpdatedTemplateProjectName
     - Save Changes
     - Verify Project Name is updated

	Delete template project
     - Open Created Template Project
     - Navigate To Settings
     - Open General Settings
     - Open Advanced Settings
     - Click Delete Project
     - Enter the deletion phrase    GroupName/UpdatedTemplateProjectName
     - Confirm Project Deletion
     - Verify Project Is Deleted
