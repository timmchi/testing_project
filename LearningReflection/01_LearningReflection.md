## 2. How did you write or manage your test case? Describe the process.

After that, I tried to do each process by myself (e.g., registration), and then, I started going through the file top to bottom: first, I defined the first set of variables that I thought I would need (e.g., URLs, test data), then wrote the positive tests and finished with the negative tests. At the same time, I always kept the "LoginPage" filled example open, so that it would be easier to write things. This made the process quite smooth.
